Com os seus dados do SIGAA

Nada é gravado. O login vai direto pro SIGAA. Nenhuma credencial é salva em banco, disco ou servidor. O acesso morre quando você fecha a aba.

Este endereço não aceita a sua senha do SIGAA, e isso é de propósito. Ele é público: um link que circula num grupo de WhatsApp não é lugar de digitar senha institucional, e quem digita não tem como saber quem está do outro lado. Nenhum campo de senha aparece aqui, e o servidor recusa qualquer login que não seja o do aluno fictício.

Para usar com os seus dados de verdade, rode o Rota na sua máquina. Aí o login vai direto da sua máquina para o SIGAA:

python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app:app --port 8012

Antes disso, suba a sigaa-ufba-api, que faz o login com a sua sessão. O passo a passo está no README do repositório, em "Rodando com um aluno real".
